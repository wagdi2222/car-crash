# 🏎️🐪 رالي الرمال

لعبة سباق سيارات عربية ثلاثية الأبعاد في المتصفح، مستوحاة من Crash Team Racing: سباق في حلبة صحراوية مع نخيل وقباب ومآذن وجِمال، وأسلحة تهاجم بها خصومك، وتلعب مع أصدقائك عبر الإنترنت بإرسال رابط.

## المميزات
- **٦ متسابقين** بطابع عربي: صقر، ليلى، جحا، شهرزاد، سندباد، عنترة (غترة وعقال، عمامة، حجاب).
- **أسلحة وقدرات عربية:**
  - 🦅 صاروخ الصقر: يلاحق المتسابق الذي أمامك
  - 🏺 الجرّة النارية: تتدحرج وتنفجر
  - 🛢️ فخ الزيت: تتركه خلفك
  - 🧞 بساط الريح: طيران سريع حتى فوق الرمال
  - 🌪️ العاصفة الرملية: تبطئ وتعمي كل من هو أمامك
  - 🛡️ درع الصحراء: يصد ضربة واحدة
  - 🪔 مصباح علاء الدين: المارد يجعلك لا تُقهر (للمتأخرين!)
- **انجراف مع توربو** بثلاث مراحل (أزرق ← برتقالي ← بنفسجي)، منصّات تسارع، وانطلاقة توربو عند البداية.
- **موسيقى مُولّدة** على مقام الحجاز مع إيقاع المقسوم على الدربكة.
- **لعب جماعي عبر الإنترنت** حتى ٨ لاعبين (مع إكمال الباقي بمتسابقين آليين).
- يعمل على **الكمبيوتر والجوال** (أزرار لمس).

## اللعب مع الأصدقاء
1. افتح اللعبة واضغط **«العب مع أصدقائك»**.
2. انسخ الرابط أو أرسله عبر واتساب.
3. عندما يدخل أصدقاؤك ويظهرون في القائمة، اضغط **«ابدأ السباق!»**.

الاتصال يتم مباشرة بين المتصفحات (WebRTC عبر [PeerJS](https://peerjs.com))، لذا لا تحتاج إلى خادم خاص. المضيف هو من يدير المتسابقين الآليين، لذا يجب أن تبقى صفحته مفتوحة وظاهرة أثناء السباق.

> ملاحظة: بعض الشبكات (مثل بعض شبكات الجوال أو الشركات) قد تمنع الاتصال المباشر. إذا لم يستطع صديقك الدخول جرّبوا شبكة Wi-Fi أخرى.

## التحكم
| الزر | الوظيفة |
|---|---|
| ↑ / W | تسارع |
| ↓ / S | فرامل / رجوع |
| ← → / A D | توجيه |
| مسافة / Shift | قفزة وانجراف |
| F / Enter | استخدام السلاح (مع ↓ للرمي للخلف) |

## النشر (GitHub Pages)
اللعبة ملفات ثابتة فقط (HTML/JS) ولا تحتاج إلى بناء.
1. في المستودع على GitHub: **Settings ← Pages ← Source: GitHub Actions**.
2. أي دفع (push) إلى الفرع سيشغّل `.github/workflows/pages.yml` وينشر اللعبة على:
   `https://<اسم-المستخدم>.github.io/car-crash/`

### التشغيل محلياً
```bash
npx http-server -c-1 .
# ثم افتح http://localhost:8080
```
